# 아두이노 센서 연동 설정 가이드

이 문서는 CNC 밀링 머신 모니터링 시스템에 아두이노 센서를 연결하고 설정하는 방법을 설명합니다.

## 필요한 하드웨어

- 아두이노 보드 (Arduino UNO, MEGA, Nano 등)
- 가속도 센서 (ADXL335 또는 MPU6050)
- 온도 센서 (선택 사항, LM35 등)
- 연결 케이블 및 브레드보드

## 연결 방법

### ADXL335 가속도 센서 연결

- VCC -> 아두이노 3.3V
- GND -> 아두이노 GND
- X -> 아두이노 A0
- Y -> 아두이노 A1
- Z -> 아두이노 A2

### LM35 온도 센서 연결 (선택 사항)

- VCC -> 아두이노 5V
- GND -> 아두이노 GND
- OUT -> 아두이노 A3

## 스케치 업로드

1. Arduino IDE를 설치합니다.
2. `arduino_example` 폴더에 있는 `sensor_example.ino` 파일을 엽니다.
3. 사용 중인 센서에 맞게 핀 번호와 보정값을 수정합니다.
4. 아두이노 보드를 선택하고 포트를 설정합니다.
5. 스케치를 업로드합니다.

## 시스템 연결

1. 아두이노 보드를 USB 케이블로 컴퓨터에 연결합니다.
2. CNC 밀링 머신 모니터링 시스템을 실행합니다.
3. 웹 인터페이스에서 "센서 연결" 버튼을 클릭합니다.
4. 시스템이 자동으로 아두이노를 감지하고 연결합니다.

## 데이터 형식

센서 데이터는 다음과 같은 JSON 형식으로 전송됩니다:

```json
{
  "accelX": 0.123,
  "accelY": -0.045,
  "accelZ": 1.002,
  "vibration": 1.156,
  "temp": 25.4
}
```

- `accelX`, `accelY`, `accelZ`: 각 축의 가속도 (g 단위)
- `vibration`: 3축 진동 강도 (RMS)
- `temp`: 온도 (섭씨)

## 문제 해결

1. **연결 실패**
   - 다른 USB 포트 시도
   - 아두이노를 재시작
   - 드라이버 재설치

2. **데이터가 표시되지 않음**
   - 시리얼 모니터로 출력 확인
   - 보레이트(9600) 확인
   - 센서 연결 확인

3. **데이터 오차가 큼**
   - 센서 보정값 조정
   - 노이즈 필터링 적용
   - 센서 위치 재조정

## 커스텀 센서 추가

추가 센서를 사용하려면 `sensor_example.ino` 파일을 수정하고 JSON 출력 형식에 새 센서 데이터를 추가하면 됩니다. 시스템은 자동으로 새 데이터 필드를 인식하고 표시합니다.
