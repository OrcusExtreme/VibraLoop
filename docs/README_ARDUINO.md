# 아두이노 센서 연동 설정 가이드

이 문서는 CNC 밀링 머신 모니터링 시스템에 진동(가속도) 센서를 연결하고 설정하는 방법을 설명합니다.
서버(`cnc_app.py`)는 화면에서 고른 통신 속도로 센서 포트를 열고(115200 또는 500000 bps), 들어온 3축 가속도로 이상 진동을 분석합니다.

## 필요한 하드웨어

- 센서 보드: 아두이노 보드(Arduino MEGA, UNO, Nano 등) 또는 Teensy(아두이노 IDE + Teensyduino)
- 가속도 센서: **MPU6050** 또는 ADXL335 (예제 펌웨어)
- 연결 케이블 및 브레드보드

지금 프로그램(edit_analysis2.md P01–P12)은 새 하드웨어 없이 기존 MPU6050과 아두이노·Teensy로 동작합니다. 바뀐 부분은 PC 쪽
프로그램이고, 센서 쪽은 고속 펌웨어를 다시 올리는 것만 필요합니다. 구성별로 쓸 수 있는 기능은 아래 [기존 하드웨어로 쓰기](#기존-하드웨어로-쓰기)를 보세요.

## 펌웨어 선택

| 펌웨어 | 센서 | 통신 속도 | 샘플링 | 용도 |
| :--- | :--- | :--- | :--- | :--- |
| `arduino/MPU6050_fast/MPU6050_fast.ino` (새 데이터 수집 권장) | MPU6050 (I2C) | 500000 | 1 kHz, ±8 g, 저역통과 약 184 Hz | 데이터 수집, 감지 |
| `arduino/MPU6050/MPU6050.ino` (기존) | MPU6050 (I2C) | 115200 | 약 100 Hz, ±2 g, 저역통과 꺼짐 | 기존 학습 데이터(`data/학습 데이터/`)와 같은 조건 |
| `arduino/MPU6050_standalone/MPU6050.ino` | MPU6050 (I2C) | 115200 | 위 기존 펌웨어와 같음 (사본) | |
| `arduino/arduino_example/sensor_example.ino` | ADXL335 + LM35 (아날로그) | 115200 | 약 100 Hz | 예제 |

기존 펌웨어의 한계 (분석: [edit_analysis.md](../edit_analysis.md) 2.6, 3.1):

- JSON 한 줄씩 보내 115200 bps에서 초당 약 100줄이 한계이고, 서버가 받은 시각만 남아 실제 측정 간격을 알 수 없습니다.
- ±2 g에서 값이 잘리고, 저역통과 필터가 꺼져 있어 50 Hz 이상의 진동이 낮은 주파수로 접혀(앨리어싱) 기록됩니다.

고속 펌웨어는 센서 내부 FIFO로 일정한 간격의 샘플을 모아 일련번호와 함께 보내므로, 서버가 실제 측정 시각(일련번호 ÷ 샘플링)과
빠진 샘플 수를 알 수 있습니다. 다만 MPU6050 가속도 대역폭은 최대 약 260 Hz라 날 통과·채터 주파수(수백 Hz 이상)는 볼 수 없습니다.
주파수 분석이 필요하면 광대역 진동 센서(예: ACCEL 14 CLICK + Teensy)를 아래 고속 형식으로 보내도록 펌웨어를 작성하세요.

### 기존 하드웨어로 쓰기

서버는 센서 샘플링으로 판정 창을 고릅니다. 400 Hz 이상이면 0.2초 창을 0.05초마다, 그보다 느리면 1초 창을 0.25초마다 평가합니다.

| 구성 | 준비 | 쓸 수 있는 기능 |
| :--- | :--- | :--- |
| MPU6050 + 기존 펌웨어 (약 100 Hz) | 없음 | 1초 창, 연속 초과 판정, 온라인 대응·정지·재가공. 주파수 특징과 빠른 차단은 없습니다. 실제 가공 데이터로 확인한 유일한 구성입니다. |
| MPU6050 + 고속 펌웨어 (1 kHz) | 펌웨어 업로드, 통신 속도 500000 | 0.2초 창, 접힘(앨리어싱)을 고려한 주파수 특징, 2단계 판정(빠른 차단 + CUSUM, 기본은 기록 전용). 처음에는 1 kHz 감지 모델이 없어 1초 창 모델로 감지하고 화면에 알립니다([펌웨어를 바꾼 뒤](#펌웨어를-바꾼-뒤-감지-모델)). |
| 아두이노 UNO·Nano·MEGA (고속 펌웨어) | | 1 kHz 텍스트 출력은 초당 약 25 kB로, 500000 bps 대역(약 50 kB/s)의 절반쯤입니다. 실제 보드에서는 아직 확인하지 않았습니다. |
| Teensy (고속 펌웨어) | Teensyduino 설치 | 표준 아두이노 함수만 써서 그대로 빌드될 것으로 봅니다(확인 전). USB 시리얼이라 통신 속도 값과 관계없이 빠릅니다. |
| Teensy + 광대역 센서 (예: ACCEL 14 CLICK) | 고속 형식(`#H`, `A,`)으로 보내는 펌웨어 작성 (저장소에 없음) | 위 기능에 더해, 샘플링이 날 통과 주파수의 2배를 넘으면 채터 주파수로 회전수를 계산하는 규칙까지 씁니다. |

MPU6050으로 안 되는 것과 대신하는 방법:

- **채터 주파수로 회전수 정하기:** 1 kHz에서는 500 Hz까지만 볼 수 있어, 2날 공구 16000–24000 rpm의 날 통과 주파수(533–800 Hz)와
  그보다 높은 채터 주파수가 접혀 보입니다. 그래서 이 규칙은 쓰지 않고 로그에 이유를 남깁니다. 안정한 회전수는 ramp 시험으로 학습한
  안정 한계 모델(진동 크기만 사용)이 정합니다.
- **장비에서 확인할 것(P02):** 헤더의 `fs`가 1000 근처인지, 일련번호가 1씩 늘고 `#O`가 없는지, 저역통과 184 Hz와 260 Hz의 공회전
  스펙트럼 차이. 그리고 ramp 몇 개로 **채터가 184 Hz 아래에서도 진동 크기로 보이는지** 확인합니다. 보이지 않으면 광대역 센서
  (Teensy + ACCEL 14 CLICK이 남아 있다면 그것, 없으면 USB 마이크)가 필요합니다.

## 연결 방법

### MPU6050

- VCC -> 아두이노 5V (모듈에 레귤레이터가 없으면 3.3V)
- GND -> 아두이노 GND
- SDA -> MEGA 20번 핀 / UNO·Nano A4
- SCL -> MEGA 21번 핀 / UNO·Nano A5
- 센서는 스핀들 하우징(앞 베어링 근처)에 나사나 접착으로 단단히 고정하고, 축 방향을 표시해 사진으로 남깁니다.
  세션마다 방향이 바뀌면 같은 가공도 다른 데이터처럼 보입니다.

### ADXL335 (예제 펌웨어 사용 시)

- VCC -> 아두이노 3.3V
- GND -> 아두이노 GND
- X -> A0, Y -> A1, Z -> A2
- (선택) LM35 온도 센서 OUT -> A3

## 스케치 업로드

1. Arduino IDE를 설치합니다.
2. 라이브러리 관리자에서 `MPU6050`(Electronic Cats 또는 I2Cdevlib 계열)을 설치합니다. 기존 펌웨어는 `ArduinoJson`(v6)도 필요합니다.
3. 사용할 펌웨어의 `.ino` 파일을 엽니다 (위 표 참고).
4. 보드와 포트를 선택하고 업로드합니다.
5. 시리얼 모니터를 펌웨어의 통신 속도로 열어 출력을 확인합니다.
   - 고속 펌웨어(500000 bps): `#H,device=MPU6050,fs=...` 헤더와 `A,<번호>,<x>,<y>,<z>` 줄
   - 기존 펌웨어(115200 bps): JSON 한 줄씩

고속 펌웨어는 실제 보드에서 아직 검증하지 않았습니다. 처음 사용할 때 헤더의 `fs` 값이 1000 근처인지, `A,` 줄의 번호가 1씩 늘어나는지 확인하세요.

## 시스템 연결

1. 아두이노 보드를 USB 케이블로 컴퓨터에 연결합니다.
2. 시스템을 실행합니다 (`run.bat` 또는 `bash run.sh`).
3. 웹 화면의 "센서 데이터" 영역에서 포트와 **통신 속도**(115200 / 500000)를 고르고 "연결"을 누릅니다. (포트는 자동으로 선택하지 않습니다)
4. 센서 데이터 로그에 `ACC(X:.., Y:.., Z:..)` 값이 표시되면 정상입니다. 고속 펌웨어는 자이로 값이 없어 `-`로 표시됩니다.
   - 화면에는 초당 20번만 표시합니다. 전체 데이터는 제어 영역의 **데이터 수집**으로 서버(`data/raw/`)에 저장하세요.
   - "센서 데이터 저장" 버튼은 화면에 표시된 값만 저장하는 미리보기용입니다.

## 펌웨어를 바꾼 뒤 (감지 모델)

감지 모델은 센서 설정(샘플링, 저역통과, 센서 위치)에 묶여 있습니다. 고속 펌웨어로 바꾸면 처음에는 1 kHz용 모델이 없어
1초 창 모델로 감지하고, 로그와 모델 관리 창에 "…에 맞는 감지 모델이 없어…"라고 알립니다. 다음 순서로 1 kHz 모델을 만듭니다.

1. 데이터 수집 창에서 정상 가공을 기록합니다. 공구의 날 수를 입력하고, 채터가 들리면 바로 구간을 표시합니다.
2. `python scripts/build_dataset.py` → `python scripts/train_models.py`로 학습합니다. 감지 모델(`models/detector_model.joblib`)에는
   가공 기록의 회전수로 계산한 비고조파 비율까지 들어갑니다.
3. 서버를 다시 시작하거나 모델 관리 창의 **감지기 초기화**를 누르면 그 창 설정에 새 모델을 씁니다.

정상 가공 CSV를 모델 관리 창에서 올려도 1 kHz 모델이 생기지만, CSV에는 회전수가 없어 비고조파 비율 없이 학습됩니다.
저역통과·센서 위치를 바꾸거나 다른 센서로 바꾸면 다시 기록해 학습하세요. 센서 샘플링이 모델의 학습 데이터와 10% 넘게 다르면
모델 관리 창에 표시합니다.

## 데이터 형식

### 고속 형식 (MPU6050_fast)

```text
#H,device=MPU6050,fs=1000.0,range_g=8,dlpf_hz=184   헤더: 시작할 때와 5초마다 (fs는 측정한 실제 샘플링)
A,12345,-210,4102,35                                샘플: 일련번호, x, y, z 원시값 (±8 g에서 4096 = 1 g)
#O,12500                                            센서 FIFO가 넘쳐 샘플이 빠짐: 다음 샘플의 일련번호
#E,메시지                                           오류
```

헤더의 `dlpf_hz`는 센서 로그에 표시만 하고, 아직 데이터 수집 기록(manifest)에는 남기지 않습니다(P02에서 추가 예정).

### 기존 형식

서버는 다음 형식을 모두 인식합니다 (가속도 단위: g). `seq`(일련번호)와 `t`(장치 시각, ms)를 넣으면 실제 측정 시각과 누락을 압니다.

```json
{"accel": {"x": 0.057, "y": 0.983, "z": -0.038}, "gyro": {"x": -2.07, "y": 0.82, "z": -1.84}}
{"seq": 101, "t": 12345, "accel": {"x": 0.057, "y": 0.983, "z": -0.038}}
{"accelX": 0.123, "accelY": -0.045, "accelZ": 1.002, "vibration": 1.156, "temp": 25.4}
{"x": 0.057, "y": 0.983, "z": -0.038}
```

- `accel` / `accelX`·`accelY`·`accelZ` / `x`·`y`·`z`: 각 축 가속도 (g)
- `gyro`: 각속도 (도/초, 선택)
- 이 밖의 줄(펌웨어 초기화 메시지 등)은 센서 로그에 그대로 표시만 하고 분석에는 쓰지 않습니다.

## 문제 해결

1. **연결 실패**
   - 아두이노 IDE의 시리얼 모니터 등 포트를 사용 중인 프로그램을 종료
   - 다른 USB 포트 시도, 아두이노 재시작, 드라이버 재설치

2. **데이터가 표시되지 않음**
   - 화면에서 고른 통신 속도가 펌웨어와 같은지 확인 (고속 펌웨어는 500000)
   - 시리얼 모니터로 출력 확인, 센서 배선(SDA/SCL) 확인
   - 고속 펌웨어는 헤더(`#H`)를 받기 전까지(최대 5초) 샘플을 쓰지 않습니다.

3. **값이 끊기거나 빠짐**
   - 데이터 수집 창과 기록 요약에 빠진 샘플 수가 표시됩니다. 계속 생기면 USB 케이블·허브, 통신 속도를 확인하세요.
   - 기존 펌웨어는 JSON 한 줄(약 100바이트) × 100Hz로 115200 bps 대역폭의 약 90%를 써서 출력 항목을 늘릴 수 없습니다.

## 커스텀 센서 추가

다른 센서는 고속 형식(`#H` 헤더 + `A,번호,x,y,z`)으로 보내는 것을 권장합니다. 헤더의 `fs`와 `range_g`만 맞으면 서버가 그대로 처리하고,
샘플링이 400 Hz 이상이면 회전 주파수 고조파를 뺀 주파수 특징(채터 주파수 추정)도 계산합니다.
측정한 채터 주파수로 회전수를 바꾸는 규칙은 샘플링이 날 통과 주파수의 2배를 넘을 때만 씁니다(예: 2날 24000 rpm이면 1.6 kHz 초과).
