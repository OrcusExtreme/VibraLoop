# 아두이노 센서 연동 설정 가이드

이 문서는 CNC 밀링 머신 모니터링 시스템에 진동(가속도) 센서를 연결하고 설정하는 방법을 설명합니다.
서버(`cnc_app.py`)는 센서 포트를 **115200 bps**로 열고, 들어온 3축 가속도로 이상 진동을 분석합니다.

## 필요한 하드웨어

- 아두이노 보드 (Arduino MEGA, UNO, Nano 등)
- 가속도 센서: **MPU6050 (권장, 기본 펌웨어)** 또는 ADXL335 (예제 펌웨어)
- 연결 케이블 및 브레드보드

## 펌웨어 선택

| 펌웨어 | 센서 | 전송 형식 | 주기 |
| :--- | :--- | :--- | :--- |
| `arduino/MPU6050/MPU6050.ino` (권장) | MPU6050 (I2C) | `{"accel":{"x","y","z"},"gyro":{"x","y","z"}}` | 10ms (100Hz) |
| `arduino/MPU6050_standalone/MPU6050.ino` | MPU6050 (I2C) | 위와 동일 (같은 내용의 사본) | 10ms (100Hz) |
| `arduino/arduino_example/sensor_example.ino` | ADXL335 + LM35 (아날로그) | `{"accelX","accelY","accelZ","vibration","temp"}` | 10ms (100Hz) |

모두 115200 bps로 전송합니다. 이상 진동 판정 모델은 약 100Hz로 수집한 데이터(`data/학습 데이터/`)로 학습되므로,
센서도 같은 주기로 보내야 분석 시간 축(윈도우 100샘플 ≈ 1초, 분석 단위 1000샘플 ≈ 10초)이 학습 때와 맞습니다.

## 연결 방법

### MPU6050

- VCC -> 아두이노 5V (모듈에 레귤레이터가 없으면 3.3V)
- GND -> 아두이노 GND
- SDA -> MEGA 20번 핀 / UNO·Nano A4
- SCL -> MEGA 21번 핀 / UNO·Nano A5

### ADXL335 (예제 펌웨어 사용 시)

- VCC -> 아두이노 3.3V
- GND -> 아두이노 GND
- X -> A0, Y -> A1, Z -> A2
- (선택) LM35 온도 센서 OUT -> A3

## 스케치 업로드

1. Arduino IDE를 설치합니다.
2. MPU6050 펌웨어를 쓰는 경우 라이브러리 관리자에서 `MPU6050`(I2Cdevlib 계열)과 `ArduinoJson`(v6)을 설치합니다.
3. 사용할 펌웨어의 `.ino` 파일을 엽니다 (위 표 참고).
4. 보드와 포트를 선택하고 업로드합니다.
5. 시리얼 모니터(115200 bps)에서 JSON이 한 줄씩 출력되는지 확인합니다.

## 시스템 연결

1. 아두이노 보드를 USB 케이블로 컴퓨터에 연결합니다.
2. CNC 밀링 머신 모니터링 시스템(`python cnc_app.py`)을 실행합니다.
3. 웹 화면의 "센서 데이터" 영역에서 포트를 선택하고 "연결" 버튼을 클릭합니다. (포트는 자동으로 선택하지 않습니다)
4. 센서 데이터 로그에 `ACC(X:.., Y:.., Z:..)` 값이 표시되면 정상입니다.
   "센서 데이터 저장" 버튼으로 받은 값을 `data/학습 데이터/`와 같은 CSV 형식으로 저장할 수 있습니다.

## 데이터 형식

서버는 다음 형식을 모두 인식합니다 (가속도 단위: g).

```json
{"accel": {"x": 0.057, "y": 0.983, "z": -0.038}, "gyro": {"x": -2.07, "y": 0.82, "z": -1.84}}
{"accelX": 0.123, "accelY": -0.045, "accelZ": 1.002, "vibration": 1.156, "temp": 25.4}
{"x": 0.057, "y": 0.983, "z": -0.038}
```

- `accel` / `accelX`·`accelY`·`accelZ` / `x`·`y`·`z`: 각 축 가속도 (g)
- `gyro`: 각속도 (도/초, 선택)
- 이 밖의 줄(펌웨어 초기화 메시지 등)은 센서 로그에 그대로 표시만 하고 분석에는 쓰지 않습니다.

## 문제 해결

1. **연결 실패**
   - 아두이노 IDE의 시리얼 모니터 등 포트를 사용 중인 프로그램을 종료
   - 다른 USB 포트 시도, 아두이노 재시작, 드라이버 재설치

2. **데이터가 표시되지 않음**
   - 시리얼 모니터로 출력 확인
   - 보레이트(115200) 확인
   - 센서 배선(SDA/SCL) 확인

3. **값이 끊기거나 깨짐**
   - JSON 한 줄(약 100바이트) × 100Hz는 115200 bps 대역폭의 약 90%를 사용합니다.
     출력 항목을 늘리면 대역폭이 부족해지므로, 늘려야 한다면 펌웨어와 `cnc_app.py`의 `ARDUINO_BAUD_RATE`를 함께 올리세요.

## 커스텀 센서 추가

다른 센서를 쓰려면 위 데이터 형식 중 하나로 한 줄에 하나의 JSON을 보내도록 펌웨어를 작성하면 됩니다.
진동 분석에는 3축 가속도(g 단위, 약 100Hz)만 사용합니다.
